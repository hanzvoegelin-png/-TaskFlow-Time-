# ⏱️ TaskFlow & Time — Gestor de Tarefas com Cronômetro e Agendamento

🔗 **Demonstração Online:** [https://hanzvoegelin-png.github.io/FlowTask/](https://hanzvoegelin-png.github.io/FlowTask/)

Uma aplicação web moderna, leve e intuitiva desenvolvida para organizar sua rotina diária de tarefas, calcular estimativas de horários e monitorar a execução em tempo real com cronômetro integrado e suporte a pausas.

---

## 🚀 Funcionalidades

* 📅 **Agendamento Inteligente:** Defina o horário de início, duração esperada em minutos e o tempo de pausa planejado. A aplicação calcula o horário previsto de término automaticamente.
* ⏱️ **Cronômetro Interativo:** Inicie o cronômetro para cada tarefa diretamente na lista. Um painel em destaque (Hero) exibe o tempo decorrido em tempo real.
* ⏸️ **Controle de Estado:** Alterne facilmente entre os estados *Em Andamento*, *Em Pausa*, *Pendente* e *Concluído*.
* 📊 **Filtros e Contadores:** Filtre suas tarefas rapidamente por status (*Todas*, *Em Execução*, *Pendentes*, *Concluídas*).
* 💾 **Persistência de Dados (Local Storage):** Seus dados e cronômetro ativo ficam salvos no próprio navegador.
* 🌙 **Modo Escuro / Claro:** Alternância rápida de tema ajustada para o conforto visual do usuário.
* 📱 **Design Responsivo:** Construído com Tailwind CSS para garantir excelente visualização em computadores, tablets e celulares.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica do documento.
* **Tailwind CSS:** Estilização moderna e utilitária via CDN.
* **JavaScript (ES6+):** Lógica dinâmica, manipuladores de evento, timers e salvamento via `localStorage`.
* **FontAwesome:** Ícones visuais de status e botões interativos.
